# Optional graphite-and-watercolor style

Adapted from Sabura's historical `product/design/sabura-icon-system/board-shapes-concept.html`.
The recipes below are self-contained; that repository file is not required to use
this skill. The Hand/size/weight/color hierarchy was subsequently tested together
in the editor's image-story section.

| Element | Starting recipe |
| --- | --- |
| Board title | Standalone; Hand; XL 40; Bold; left; blue #1971c2 |
| Section heading | Standalone; Hand; L 28; Bold; left; blue #1971c2 |
| Shape label | Hand; M 20; Bold; centered; dark #1e1e1e |
| Caption | Separate text; Hand; S 14; regular; left or centered; dark #1e1e1e |

Optional caption opacity: 75%, from the concept, not tested in the combined sample.
Use M 20 captions when S is too small at the intended presentation zoom. Shorten
or wrap long titles rather than forcing the entire board to shrink to fit them.

Warm paper (#fcfaf6), a restrained dot grid, and dark graphite structure set the
base. Pastels: blue #a5d8ff, green #b2f2bb, yellow #ffec99, pink #ffc9c9,
purple #eebefa, and white. Choose a small consistent subset. These are not mandatory
semantic categories. Labels must carry meaning without color alone.

The historical concept's watercolor pigment and doubled graphite lines are
rendering treatments, not a requirement to invent new editor controls. Whole-object
opacity can fade labels and outlines too; it is not fill-only translucency.
Use available styles and inspect the result. An imported illustration can provide
watercolor texture without changing the renderer.

Use consistent dimensions for equivalent objects, room for captions, and enough
space for routes. Prefer solid main flow and labeled/dashed alternatives when
that helps the story; don't encode semantics through line style alone. Avoid
connector/caption intersections. Design chapters for readable zoom, with a whole
board overview for orientation. Spacing and color roles are adaptable guidance,
not fixed design tokens or enforced shape meanings.
