# Security policy

## Supported version

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not publish exploit details in a public issue. Use GitHub's private
vulnerability reporting feature from the repository's **Security** tab. If that
option is unavailable, open an issue containing no sensitive details and ask
the maintainer for a private reporting channel.

Include the affected version, reproduction conditions, expected impact, and a
minimal proof of concept when it is safe to do so.

Sabura is designed to run locally without network access. Reports involving
document parsing, embedded content, browser execution, exported files, or the
live-agent boundary are particularly useful.
